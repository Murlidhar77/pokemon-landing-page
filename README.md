# Pokémon Landing Page ⚡

A vibrant, Pokémon-inspired landing page featuring Pikachu, built using HTML and CSS.

## 🌟 About the Project

This project is a creative landing page designed to showcase Pikachu from Pokémon Generation I. It features a bold yellow hero section, Pokémon-themed decorations, and a clean layout.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS positioning and media queries for responsive layouts

## ✨ Features

- Pikachu-focused hero section
- Pokémon logo and themed visual elements
- Custom Poké Ball decoration using CSS
- Responsive layout for desktop and smaller screens
- Organized HTML structure and custom CSS styling

## 📁 Project Structure

```text
pokemon-landing-page/
├── index.html
├── pokemon.css
└── image/
    ├── pokemon.png
    ├── menu.png
    └── pikachu.png
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Enjoy the Pokémon landing page!

## 📚 What I Learned

- Structuring a webpage with HTML
- Styling and positioning elements with CSS
- Creating decorative elements using pseudo-elements
- Making layouts responsive with CSS media queries
